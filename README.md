# 浏览器实用插件三件套（Browser Toolkit Extensions）

一套日常高频自用、边界清楚、纯本地运行的轻量 Chrome / Edge（Manifest V3）浏览器插件合集，来自播客节目中分享的 AI 辅助开发实战案例。

所有代码完全公开、无广告、无后台埋点、不收集任何隐私或账号凭据。

---

## 包含插件

### 1. 视频提亮与声音放大 (`video-brighten-audio`)
专治网页看英美剧（如《权力的游戏》《龙之家族》等暗黑画面剧集）**画面黑漆漆看不清、人声小但爆炸声震耳欲聋**的痛点：
- **画面提亮（0–100 滑块）**：实时拉高网页 `<video>` 亮度，归零即无痕恢复网页原始渲染。
- **声音放大（0–100 滑块）**：基于 Web Audio 独立增益控制，最高约 **+24 dB**。
- **自动拉平音量**：动态压缩压低过响峰值，避免声音忽大忽小，同时不粗暴切断底噪、不产生抽吸感。

> 提示：浏览器安全策略要求页面有过一次点击操作后才允许接入音频上下文；如遇声音异常，刷新当前网页重试即可。

### 2. 网页护眼阅读模式 (`web-reading-mode`)
一键切换当前网页配色，适合长时间网页办公与夜间阅读：
- **夜间模式**：黑底浅字，高对比度不刺眼。
- **豆绿阅读**：柔和护眼绿底 + 深色文字。
- **户外增强**：强明暗对比，适合强光环境。
- **一键复原**：仅修改本地页面显示样式，随时恢复原样。

### 3. 网页音视频辅助保存 (`web-media-helper`)
识别当前网页可访问的视频与音频资源并保存到本地下载目录：
- 优先识别网页媒体元素与已加载媒体资源，支持常见直链格式（MP4 / WebM / MP3 / M4A）。
- 普通 MP4 / M4V 支持在浏览器本地无损提取音频（内置 `mp4box.js`，纯本地处理，不上传服务器）。
- 仅在用户主动点击时处理当前标签页，**不会绕过付费墙、登录鉴权或 DRM 加密保护**。

## 快速安装（Chrome / Edge 通用）

1. 点击右侧 **Releases** 下载最新版压缩包并**完整解压**到一个固定不删的文件夹（或直接 `git clone` 本仓库）。
2. 在浏览器地址栏打开扩展管理页：
   - **Chrome**：`chrome://extensions/`（打开右上角「开发者模式」）
   - **Edge**：`edge://extensions/`（打开左下角「开发人员模式」）
3. 点击「加载已解压的扩展程序」（Edge 叫「加载解压缩的扩展」），分别选择 `extensions/` 下的对应子文件夹即可。
4. 点击浏览器右上角拼图图标，将插件固定到工具栏方便随时使用。

> **注意**：加载后请勿删除或移动本地的插件文件夹，否则插件会失效。
