网页媒体下载

打开包含视频或音频的网页，点击 Chrome 工具栏中的插件，选择「下载音频」或「下载视频」。插件会优先识别网页媒体元素和已加载的媒体网络资源；B站和小红书仍使用原有平台专用逻辑。

支持范围

常见直接媒体文件（如 MP4、WebM、MP3、M4A）通常可以直接保存，并尽量保留原始格式。普通 MP4/M4V 视频可尝试在本地无损提取音频。文件保存到 Chrome 下载目录，重名自动编号。

限制

检测到 M3U8 或 MPD 只代表识别到了 HLS/DASH 播放清单，当前版本还不能把所有分段流合并为完整视频。blob: 临时地址、DRM 加密、直播、需要特殊鉴权的媒体及网站结构变化也可能无法下载。浏览器内解析/提取限制为 512 MB；直接下载不受该本地处理限制。不会绕过付费、登录或访问控制。

权限

读取当前页面需要 Chrome 的活动标签页权限。若在普通网站尝试从视频提取音频，Chrome 会询问是否允许插件访问 HTTP/HTTPS 网站（权限提示范围为所有此类网站），用于在本地读取跨域媒体数据。获得权限不代表插件会自动扫描网页；插件只在你主动点击时处理当前标签页。不上传媒体、不收集账号密码或 Cookie。

失败时

先在页面播放几秒，再打开插件重试。若提示分段流、blob 地址或访问受限，当前版本可能无法直接处理该资源；这不是普通下载按钮能够解决的格式问题。
